# BrandSip - Custom Branded Water Bottles

BrandSip provides custom-branded water bottles for businesses, events, colleges, weddings, conferences, and promotional campaigns.

## Features
- Modern, premium React/Vite UI
- Tailwind CSS styling
- Custom Bottle Quote Calculator
- Bottle Customizer with logo upload preview
- Mobile-responsive design

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Hook Form
- Lucide React

## Local Setup
1. Clone the repository: `git clone https://github.com/Slockahuja/BrandSip.git`
2. Navigate to the directory: `cd BrandSip`
3. Install dependencies: `npm install`
4. Start development server: `npm run dev`

## Deployment
This project is configured for GitHub Pages deployment.
The Vite build process sets the base URL to `/BrandSip/`.
Push to the `main` branch to trigger the GitHub Actions deployment workflow (if configured) or run deployment scripts.

## Configuration
### Pricing Configuration
You can easily adjust all pricing and sizing information in `src/data/pricing.ts`.

### Contact Configuration
You can edit phone numbers, emails, locations, and social links in `src/data/contact.ts`.

### FAQ
Modify FAQ entries in `src/data/faq.ts`.
